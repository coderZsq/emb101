# EMB101 · 从代码到真实世界

面向有编程基础、硬件零基础学习者的互动课程。第一阶段围绕 Arduino Nano ESP32，从认识引脚和电路到制作按钮控制 LED 的小作品；3D 打印外壳和进阶课程将在后续展开。

## 运行

需要 Node.js 和 npm：

```sh
npm install
npm run dev
```

打开终端显示的地址。`npm run build` 生成生产构建。进度存储在当前浏览器中；网页实验是简化模拟，不连接硬件。

实物实验需要 Arduino Nano ESP32、数据 USB-C 线、面包板、杜邦线、普通红色 LED、330Ω 电阻和按钮。修改接线前断电；Nano ESP32 信号引脚为 3.3V。详见课程内的接线和官方资料链接。
