# EMB101 ESP32-S3 第一阶段课程计划

## 目标

让有编程基础、电子硬件零基础的学习者，在不焊接的情况下，逐步完成 ESP32-S3 输入、输出和本地 Wi-Fi 控制作品。

## 固定教学环境

- ESP32-S3-DevKitC-1，ESP32-S3-WROOM-1-N8R8，排针已焊接。
- Mac、Arduino IDE 2、Espressif Arduino 开发板支持包。
- USB-to-UART 数据线、400 孔无焊面包板、至少 4 根公对母杜邦线、LED、330Ω 电阻和四脚按钮。
- 开发板放在面包板旁，用母头接开发板预焊针脚、公头插面包板，不把开发板硬压进面包板。
- LED 固定用 GPIO4，按钮固定用 GPIO5；使用 3.3V GPIO，不接外部 5V。

## 八节课程

1. 器材清单与免焊规格。
2. 认识开发板方向、接口和课程针脚。
3. 在 Mac 安装工具并上传首个串口程序。
4. 面包板连接组、中央沟和杜邦线。
5. GPIO4、串联电阻和 LED 输出。
6. GPIO5、INPUT_PULLUP 和按钮输入。
7. 按钮控制 LED 的完整交互。
8. ESP32-S3 连接本地 Wi-Fi，通过浏览器控制 LED。

## 教学要求

- 每课按目标、器材、编号步骤、接线/板子示意、预期结果、检查点和排错提示组织；LED 使用第 10/12 行，按钮使用第 20/22 行。
- 一次只增加一个硬件概念；模拟实验清楚标明不会控制实物。
- 改线前拔 USB；LED 必须串联电阻；开发板方向和接线行号固定。
- 错答后解释具体原因，并指向要回看的步骤；课程进度保存在浏览器中。
- 交付时检查课程文字、示意图与步骤中型号、引脚、孔位和电流路径一致。
