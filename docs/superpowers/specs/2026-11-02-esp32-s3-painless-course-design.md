# EMB101 ESP32-S3 无痛入门课程设计

## 目标与学习者

课程面向有编程基础、但从未使用开发板、面包板或杜邦线的学习者。学习者使用 Mac，电子硬件从零开始。课程目标是让学习者不焊接、不猜引脚、不跳步骤，独立完成一个 ESP32-S3 交互作品，并理解每条接线的作用。

课程语言为简体中文。编程概念沿用学习者已有基础；遇到新硬件概念时，用现象、图示和小实验解释。

## 固定硬件与软件

- 开发板：Espressif ESP32-S3-DevKitC-1，目标模块为 ESP32-S3-WROOM-1-N8R8；购买时必须确认两排排针已焊接，开箱可直接插接。
- 连接：USB 数据线连接开发板的 USB-to-UART 端口。课程明确数据线和接口形状，提醒仅充电线无法上传程序。
- 基础器材：标准 2.54 mm 无焊面包板、公对公杜邦线、普通红色直插 LED、330 Ω 电阻、适配面包板的轻触按钮。
- 软件：Mac 上的 Arduino IDE 2 与 Espressif Arduino 开发板支持包。
- LED 实验固定使用 GPIO4，不依赖板载 RGB LED。这样可以避开不同硬件版本的 RGB LED 引脚差异。
- 所有硬件实验均使用 USB 供电；课程不引入电池、焊接、外接 5 V 或市电。

## 教学原则

1. **一次只推进一个新动作。** 不在同一课里混合安装软件、看引脚图、接线和排错。
2. **先解释再操作。** 每次接线先指出将要使用的器件、孔位和连接关系，再给编号步骤。
3. **每步都有可见检查点。** 明确学习者现在应该看到什么；结果不符时给出最短检查路径。
4. **不要求猜测硬件。** 接线图固定开发板方向、板型、引脚名、面包板行列和 LED 极性；板型不匹配时先停在板型确认步骤。
5. **模拟与实物分明。** 浏览器模拟仅用于理解概念；页面清楚标明模拟不会连接或控制开发板。
6. **安全提示贴近操作。** 改线前拔 USB，GPIO 使用 3.3 V 逻辑，LED 必须串联电阻，不把 GPIO 直接连到电源或 GND。

## 课程路线

### 00 · 开始之前：准备一套不用焊接的器材

展示完整购物清单、关键规格和排针已焊接的识别方式；解释数据线要求、工具作用和 USB 供电边界。完成标准：学习者能逐项核对开发板、线材和元件。

### 01 · 认识 ESP32-S3 开发板

使用板子正反面标注图识别 USB-to-UART、USB、BOOT、RESET、3V3、GND、GPIO 排针，并固定板子方向。完成标准：学习者能找到课程要用的接口和 GPIO。

### 02 · 连接 Mac 并上传第一个程序

按步骤安装 Arduino IDE 2 与 ESP32 支持包，接入开发板、选择板型和端口，上传最小程序并在串口监视器看到预期文本。为无端口、上传失败和充电线问题提供分支排错。

### 03 · 面包板与杜邦线：先练连接，不上电

通过图示讲清面包板中央沟、同一行的连接组和杜邦线的插拔方式；先用不带电的练习验证哪些孔相通。完成标准：学习者能根据图指出一条连续连接路径。

### 04 · 接一颗 LED：输出与限流电阻

先断电，再按固定方向把 GPIO、串联电阻、LED 和 GND 连成回路；代码上传后确认 LED 亮灭。图示明确 LED 长短脚、面包板孔位以及每段连接。

### 05 · 接一个按钮：读取输入

在断电状态下连接按钮，解释四脚按钮的导通关系和 INPUT_PULLUP 的按下/松开读数，再通过串口输出状态验证。

### 06 · 合成作品：按按钮控制 LED

复用已验证的 LED 与按钮电路，编写输入、判断和输出逻辑。完成标准：按下点亮、松开熄灭，并能用串口定位常见接线错误。

### 07 · 连接 Wi-Fi：用浏览器控制作品

将 ESP32-S3 接入学习者的本地 Wi-Fi，在浏览器打开一个简单控制页面，切换 LED 状态。说明网络名称、密码和访问地址分别填在哪里；提供连接失败的检查步骤。

## 每课页面结构

每课按“本课目标 → 需要的器材 → 先看结果 → 编号操作步骤 → 接线/板子示意 → 检查点 → 常见问题 → 小练习 → 下一课”组织。遇到硬件操作时，在相关步骤旁标明是否需要断电。代码块只包含本课所需的完整可运行代码，并说明应替换的参数。

课程导航按先修顺序呈现；每课有可重复查看的步骤。进度保存在当前浏览器，不阻止学习者回看已完成内容。小测答错时提供具体原因和回到对应步骤的提示，不只显示“再试一次”。

## 课程边界

第一阶段不讲焊接、锂电池供电、复杂传感器、RTOS、ESP-IDF 或 3D 打印。Wi-Fi 作品只在本地网络中运行，不部署公网服务。

## 实现范围

保留现有轻量网页应用的导航、进度存储和响应式布局；重写旧 Nano ESP32 课程内容、板子示意、实验和小测。新增适配 ESP32-S3-DevKitC-1 的板子标注图、面包板连接图及逐步检查内容。不会继续保留与新硬件目标冲突的 Nano ESP32 专属 D2/D3 说明。

## 验收标准

- 新手在购买前可依规格判断是否为免焊接所需器材。
- 课程指定一个确定板型和一个确定的 USB 上传接口，不把多个开发板混写成通用步骤。
- 每个实物实验均可从图和步骤独立搭建，不需要推断孔位或电流路径。
- 每个关键操作均有预期结果及失败时的下一步检查方式。
- 课程明确指出模拟不控制实物，并在每次改线前提示断电。
- 课程最终作品完整覆盖 GPIO 输出、按钮输入、代码逻辑和本地 Wi-Fi 控制。
